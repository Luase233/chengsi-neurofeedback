## 审查修复

- 普通/EDF 两包的同一会话不再因推送序号或导出时状态年龄不同而误报数据冲突。仍比较原始数据、特征、事件、评分与共同附件，不覆盖或合并已归档文件。
- 上传验证和最终发布均在请求取消时等待后台工作结束，保证上传文件不会被验证线程提前关闭，临时目录完整清理。
- Mac 进程检查要求项目脚本是已知 Python 的首个脚本，避免误认其他脚本参数里的项目路径。
- Windows 同样校验实际 Python 解释器与首个脚本，仅支持当前和兼容旧版的启动参数。真实外部进程把项目路径作为普通参数且只存在旧式 PID 文件时，停止操作仍被拒绝；当前正式服务仅作只读身份与健康检查，保持运行。
- Mac 关闭操作先取得启动器锁再读取 PID，避免并发启动尚未写 PID 时提前报告关闭。
