# 导入以前的训练数据

1. 打开工作人员工作台，结束当前会话。导入不会中断训练或自行结束会话。
2. 点击左侧 **导入数据**，选择系统以前导出的 ZIP。普通“导出完整记录”和“导出原始脑电 EDF”得到的 ZIP 均支持，不用自行解压。
3. 等待完成。窗口会显示原被试编号、实机／模拟／回放来源和个人基线状态。
4. 点击 **查看训练记录** 查看该编号与来源的历史。点击 **记录回放** 会选中刚导入的会话，仍需手动点击载入，不会自动连接头环或开始采集。

导入不需要重启后端。后续训练应保持原被试编号；只有编号、来源、设备与算法配置兼容，恢复的基线才会被复用。不改旧记录的评分、基线参数或来源标签，不把单次历史记录补成新的每日训练轮次。

## 支持的包

ZIP 根目录须包含 `session.json`、`raw.csv`、`features.csv`、`events.jsonl`。可选的 `baseline.json` 用于恢复完整有效的个人基线。EDF 导出 ZIP 还可保留 EDF、分段清单、说明及历史前测参考附件。单独的 EDF、普通歌曲或任意 CSV 不作为会话导入。

`baseline-reference/` 只属于当前导出包的原前测参考片段，不会被当作另一场完整训练导入。基线不完整或不兼容时，会话仍可归档，但窗口会说明基线未恢复；后续训练可能需要重新前测。

限制为 ZIP 64 MiB、展开 512 MiB、512 个条目。过大的 EDF 包可改用普通记录包。损坏、加密、不安全路径或不完整文件会被拒绝；拒绝时不会留下半份会话。

## 重复与冲突

同一记录重复选择，或普通／EDF 两种导出只有会话推送时间、序号等易变字段不同，会提示已存在，不重复添加。原始采样、特征、事件、评分、基线或共同附件发生冲突时，导入失败并保留已有记录。

已有记录不会被合并、替换或删除。若先导入普通包，再选择带额外 EDF 附件的同一会话，原记录继续保留，窗口会说明额外附件未再次归档。需要保留 EDF 附件时，首次选用含 EDF 的完整导出包即可。

## 保存与迁移

记录保存在主程序的本地数据目录，默认 `runtime/sessions/`；完整基线另建索引，原包内副本同时保留。使用 `--data-dir` / `-DataDir` 时保存到相应配置目录。导入仅限本机工作人员，被试 iPad 不能上传记录。

跨电脑完整迁移仍可在后端停止后复制整个 `runtime`，并先备份目标数据。真实脑电、被试信息和原始导出包不要推送到公开仓库。
